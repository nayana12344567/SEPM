# Integrated Bus Time Table System (IBTTS)

## Project summary
A small web prototype to view and manage bus timetables (passenger UI + admin CRUD). This project is created for the SEPM assignment.

## Features
- Passenger-facing timetable view + search (route, stop, bus number, time)
- Admin dashboard for Create / Read / Update / Delete timetable entries
- Backend REST API to fetch and manage timetable data
- Example database schema described in Confluence (Design page)
- Link between commits/PRs and Jira issues using Jira keys (e.g., BTTS-8)
